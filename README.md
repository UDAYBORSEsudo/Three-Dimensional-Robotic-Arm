# 🤖 Three-Dimensional Robotic Arm

A 3-DOF 3D-printed robotic arm designed for movement and pick-and-place applications using Arduino and servo motor control.

## 📌 Project Overview

This project presents the design and development of a three-dimensional robotic arm using 3D-printed mechanical components, an Arduino Uno, and servo motors.

The robotic arm is designed to perform controlled movements in three-dimensional space and can be used for applications such as object handling, pick-and-place operations, and educational robotics.

## ✨ Features

- 3-DOF robotic arm
- 3D-printed mechanical structure
- Arduino Uno based control
- Servo motor based movement
- Pick-and-place operation
- Lightweight and customizable mechanical design
- Low-cost robotics platform
- Modular mechanical components

## 🛠️ Technologies Used

- Arduino Uno
- Servo Motors
- 3D Printing
- Embedded Systems
- C/C++ for Arduino
- Mechanical Design
